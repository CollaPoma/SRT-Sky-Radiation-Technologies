# SRT: Sky Radiation Technologies

**SRT** — это технический и выживаческий мод для Minecraft, действие которого происходит во **Вселенной SkySim**.
Этот мод добавляет уникальные кольца со специальными способностями, продвинутые технологии и механики постапокалипсиса.

*Разработано CollaPoma (Sky Forces).*

## 🛠️ Текущие возможности (v1.0.0 — в разработке)
- **Собственная вкладка в креативе:** `SRT: Rings` (находится на второй странице).
- **5 уникальных колец:**
    - **Кольцо полёта:** Даёт полёт в стиле креатива в режиме выживания (активируется двойным прыжком).
    - **Кольцо ночного видения:** Даёт постоянное ночное видение, пока находится в инвентаре.
    - **Кольцо скорости:** Даёт Скорость II, пока находится в инвентаре.
    - **Кольцо невидимости:** Даёт Невидимость II, пока находится в инвентаре.
    - **Кольцо радиации:** Даёт Силу II и Сопротивление II, но вызывает Голод и шанс Отравления (лучевая болезнь).
- **Собственные рецепты крафта:** Уникальные рецепты для каждого кольца (включая улучшения колец).
- **Собственные текстуры 16x16:** Нарисованный вручную пиксель-арт для всех предметов.
- **Полностью рабочий RingHandler:** Собственная система событий, которая каждый тик проверяет инвентарь игрока для применения эффектов и полёта.

## 🚀 Планируемые возможности
- Собственный GUI «Футляр для колец» для хранения до 5 колец в одном предмете.
- Продвинутые машины и реакторы (начиная с Машины радиации).
- Полноценная система радиации (распространяющейся по миру).
- Собственные анимации и 3D-модели.

## 📦 Установка
1. Установите **Minecraft Forge 1.16.5** (версия 36.2.42 или выше).
2. Скачайте последний `.jar` файл из вкладки **Releases**.
3. Поместите `.jar` файл в папку `mods`.
4. Запустите игру!

## 🧑‍💻 Для разработчиков
